This Storybook documents **`@repo/ui`**, the component library behind the
real-time collaborative editor in `apps/web`. Every component you see here is
the component the product ships — there is no separate "documentation" copy.

## Where things live

| Path                         | What it is                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| `apps/web`                   | The Next.js application: routing, Convex data, Liveblocks presence, Tiptap editor. |
| `apps/storybook`             | This site. Guides, token galleries and the Storybook configuration.                |
| `packages/ui`                | The design system. Components, hooks and the design tokens.                        |
| `packages/tailwind-config`   | Tailwind preset mapping tokens onto the theme.                                     |
| `packages/eslint-config`     | Flat ESLint configs: `base`, `react-library`, `next`, `storybook`.                 |
| `packages/typescript-config` | Shared `tsconfig` bases.                                                           |

## Running it

```bash
pnpm storybook    # just this site, on :6006 — no services needed

pnpm setup        # the full stack: install, env files, Postgres + Keycloak
pnpm dev          # every app in the monorepo
```

Storybook is the fastest way into this repo: the design system has no data
dependencies, so it runs without Docker, without a database and without
signing in.

## Using a component

Import from the layer you depend on. The import path then states, at a glance,
how deep in the system a file reaches:

```tsx
import { Button, Spinner } from "@repo/ui/atoms";
import { SearchField } from "@repo/ui/molecules";
import { DocumentTable } from "@repo/ui/organisms";
import { AppShell } from "@repo/ui/templates";
```
